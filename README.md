# 👩‍💻 Sobre mim

Sou profissional de **Quality Assurance**, atuando na garantia da qualidade de aplicações web através da análise de requisitos, planejamento e execução de testes, investigação de defeitos e validação de regras de negócio.

Minha experiência envolve:

- 🧪 Testes funcionais e exploratórios
- 🔄 Testes de regressão e integração
- 🌐 Testes de APIs REST com Postman
- 🗄️ Validação de dados utilizando SQL Server
- 🐞 Identificação, documentação e acompanhamento de bugs
- 📋 Criação de cenários, casos de teste e evidências
- 🤖 Automação de testes E2E com Cypress e JavaScript
- 🔎 Análise de requisitos e regras de negócio
- 🔁 Versionamento de código com Git e GitHub

Atualmente estou aprofundando meus conhecimentos em **automação de testes, arquitetura de testes E2E e integração contínua**, desenvolvendo projetos práticos com **Cypress, JavaScript e Node.js**.

🎓 Formação em **Gestão da Tecnologia da Informação**  
🎓 Graduanda em **Ciência da Computação**

Além da tecnologia, sou fundadora do **Patinhas Solidárias**, projeto voluntário de cinoterapia que promove acolhimento e bem-estar através da interação com cães terapeutas.

## 🎓 Desafio QA — Moodle

Projeto desenvolvido para aplicação prática de conceitos de **Quality Assurance** em uma plataforma Moodle.

O projeto reúne diferentes etapas do processo de qualidade:

- 🧪 Planejamento e criação de casos de teste
- 🐞 Identificação e documentação de bugs
- 📸 Evidências de execução
- 🤖 Automação E2E com Cypress
- 🔎 Testes exploratórios
- 📋 Validação de requisitos

### 📁 Estrutura do projeto

```text
desafio-qa-moodle/
│
├── 01_casos_de_teste/
├── 02_relatorio_de_bugs/
├── 03_evidencias/
└── 04_automacao_cypress/
```

> 🎯 **Objetivo:** demonstrar o processo completo de QA, desde a análise e planejamento dos testes até a identificação de defeitos, documentação de evidências e automação.
