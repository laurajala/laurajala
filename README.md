# 👩‍💻 Sobre mim

Atuo como Quality Assurance com foco em **testes funcionais manuais**, garantindo a qualidade de software por meio da validação de requisitos e fluxos de negócio em aplicações web.

Atualmente estou em transição para a área de **automação de testes**, estudando e desenvolvendo projetos com **Cypress, JavaScript e Node.js**, com foco em testes E2E.
